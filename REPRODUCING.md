# Reproducing this work

This file is the single entry point for reviewers. It assumes you have a CUDA GPU and
that you can accept third-party licence terms yourself (see `NOTICE`).

Short version:

```powershell
git clone <this repo> ; cd <repo>
cd program ; .\env\create_envs.ps1          # first two venvs, ~15 min; .venv-modern is built separately (section 2)
cd ..      ; python scripts\fetch_models.py --check-lock   # no downloads, instant
python scripts\fetch_models.py --all        # 164.4 GB on disk, needs `huggingface-cli login` first
cd program ; .\.venv-vl\Scripts\python.exe scripts\39_preflight.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_all_layers.ps1 -DryRun
```

---

## 1. What is and is not in the repository

| Asset | In repo? | How to obtain |
|---|---|---|
| Source code (`program/src`, `program/scripts`, `src/`) | yes | clone |
| Configs (`configs/*.yaml`) | yes | clone |
| Model weights (8 upstream checkpoints + 2 derived directories, 164.4 GB on disk) | **no** | `configs/models.lock.yaml` + `scripts/fetch_models.py` |
| Virtualenvs | **no** | `program/env/create_envs.ps1` |
| Medical images (NIH, CheXpert, PadChest, Open-i) | **no** | your own data-use agreements |
| Generated predictions / stage-2 tables & figures | **no** | regenerated by the runs below |
| Synthetic test fixtures (`tests/fixtures/`) | yes | clone (fabricated ids/hashes, no patient data) |
| Third-party paper PDFs (`references/pdf/`) | **no** | see `references/library.bib` |

Weights are deliberately not hosted here: they exceed Git and LFS limits, and MedGemma's
terms prohibit re-hosting while LLaVA-Med is research-use-only and not redistributable.

## 2. Environments

Three venvs, because the checkpoints need incompatible `transformers` lines:

| venv | torch | transformers | used for |
|---|---|---|---|
| `program/.venv-vl` | 2.5.1+cu121 | 4.51.3 | MedGemma, Qwen2.5-VL, default matrix |
| `program/.venv-chexagent` | 2.1.0+cu121 | (pinned) | CheXagent-8b, incl. 4-bit path |
| `program/.venv-modern` | 2.14.1+cu126 | 5.18.0 | Qwen3-VL-8B only |

`create_envs.ps1` (or `create_envs.sh`) builds the first two:

```powershell
cd program
.\env\create_envs.ps1
```

`.venv-modern` is not built by that script yet — create it the same way if you need
Qwen3-VL:

```powershell
cd program
py -3.10 -m venv .venv-modern
.\.venv-modern\Scripts\python.exe -m pip install --upgrade pip
.\.venv-modern\Scripts\python.exe -m pip install torch==2.14.1 torchvision --index-url https://download.pytorch.org/whl/cu126
.\.venv-modern\Scripts\python.exe -m pip install -r env\requirements-vl.txt
.\.venv-modern\Scripts\python.exe -m pip install transformers==5.18.0
```

Optional: `env/optional-bitsandbytes.txt` adds 4-bit quantisation.

## 3. Weights

`configs/models.lock.yaml` pins every checkpoint by Hugging Face repo id **and commit
revision**, so "same numbers" means "same weights, byte-identical".

```powershell
# structural check: no network, no GPU, no downloads
# (CI runs this on every push: .github/workflows/ci.yml, two jobs, CPU only)
python scripts\fetch_models.py --check-lock

# then fetch
huggingface-cli login          # required: MedGemma is gated
python scripts\fetch_models.py --all
```

Gated checkpoints (`google/medgemma-4b-it`, `google/medgemma-1.5-4b-it`) require you to
accept the Gemma Terms of Use + HAI-DEF on Hugging Face with **your own** account.
In mainland China, `HF_ENDPOINT=https://hf-mirror.com` is what made these downloads
feasible; see `docs/45_weight_download_through_cn_mirrors.md`.

LLaVA-Med needs a two-step conversion before it loads — `fetch_models.py` prints the
exact commands, and `configs/models.lock.yaml` records them under `conversion:`.

## 4. CPU-only checks (no weights, no GPU)

### 4.1 Audit CLI (Python >= 3.10, independent of the program venvs)

The installable companion tool in `audit/` recomputes denominators, response
collapse and selective-prediction coverage from prediction files. It needs only
numpy, pandas and scikit-learn:

```powershell
python -m venv .venv-audit
.\.venv-audit\Scripts\python.exe -m pip install -e "audit[dev]"
.\.venv-audit\Scripts\python.exe -m pytest -q audit/tests      # 4 passed
.\.venv-audit\Scripts\python.exe -m cxr_audit demo             # synthetic, no data
```

`make audit-install`, `make audit-cli-test` and `make audit-demo` wrap the same
commands; CI runs them on Python 3.10 and 3.12. With the frozen outputs present,
the manuscript numbers can be replayed directly (derm panel, MedGemma-1.5-4B):

```powershell
.\.venv-audit\Scripts\python.exe -m cxr_audit census `
  program\outputs\crossmodal\derm\v0\medgemma_15_4b_it\shift_predictions.jsonl
# rows 2940, unique_keys 2940, duplicates 0, parse_rate 0.95034

.\.venv-audit\Scripts\python.exe -m cxr_audit responsiveness `
  program\outputs\crossmodal\derm\v0\medgemma_15_4b_it\shift_predictions.jsonl `
  --labels actinic_keratosis,basal_cell_carcinoma,benign_keratosis,dermatofibroma,melanoma,melanocytic_nevus,vascular_lesion `
  --clean clean --shift contrast --severity severe
# distinct_clean_vectors 95, modal_share 0.1105, P1 change 0.5493

.\.venv-audit\Scripts\python.exe -m cxr_audit selective `
  program\outputs\selective_v2\medgemma_15_4b_it\risk_items_finding.csv
# confidence AUROC 0.7366, coverage@5% 0.0926; entropy/margin 0.6019, 0.0001
```

## 5. The three-layer 6K evaluation

Authoritative protocol: `docs/48_three_layer_protocol.md`. Data contract:
`docs/49_data_manifest_contract.md`.

```powershell
cd program

# 0. preflight + full-repo scan (fast, no model loaded)
.\.venv-vl\Scripts\python.exe scripts\39_preflight.py
.\.venv-vl\Scripts\python.exe scripts\45_debug_sweep.py

# 1. print the plan without running anything
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_all_layers.ps1 -DryRun

# 2. smoke test, a few minutes (must be ISOLATED from the full run, else the
#    driver refuses with exit 3 -- see docs/48 section 4.5.1)
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_all_layers.ps1 `
  -Models medgemma_4b_it -Layers openi,padchest -Limit 4 -NoAblation `
  -OutputRoot outputs\pretest -StateFile outputs\state\pretest_state.json

# 3. full run (delivered study: 7 models x 3 layers, 275,218 calls; the six
#    schema-compliant models as one matrix plus LLaVA-Med as a separate
#    contract-exempt pass). See docs/48 for the exact two-pass commands.

#    pass 1 -- the six schema-compliant models as one matrix
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_all_layers.ps1 `
  -Models medgemma_4b_it,medgemma_15_4b_it,qwen25_vl_7b_instruct,`
qwen3_vl_8b_instruct,chexagent_8b,internvl3_5_8b

#    pass 2 -- LLaVA-Med alone. It answers in prose and never satisfies the
#    JSON contract, so its stages are kept as contract-exempt evidence and
#    excluded from structured-contract metrics (Open-i prose metrics still apply).
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_all_layers.ps1 `
  -Models llava_med_v1_5_7b
```

Re-running the same command resumes: completed stages are skipped, unfinished ones continue
from a durable byte offset (`DurableJsonl`: append → fsync → atomic offset sidecar).
State lives in `program/outputs/state/run_all_layers_state.json`, predictions in
`program/outputs/matrix/{nih_eval|padchest|openi}/<model>/`.

Analysis afterwards (CPU only): scripts 75--116. The paper's main analyses are
`90_coverage_census.py`, `91_manifest_lock.py`, `87_label_hierarchy_prevalence.py`,
`88_per_label_ci_fdr.py`, `89_fixed_threshold_posthoc.py`, `104_table_consistency_check.py`,
and the items 106--116 added for the v7 controls (clean AUROC intervals, PadChest
label hierarchy, fixed-rule rerun, CheXbert cross-check, determinism, DenseNet grid,
cross-family schema, labeller agreement, LLaVA-Med NIH subset, paraphrase agreement).

## 6. Honest status of the headline numbers

The three-layer matrix is **complete**. The delivered run has 38 stage entries:
30 completed, of which 8 are flagged contract-exempt for structured-contract
metrics (six Open-i stages + two LLaVA stages; Open-i prose metrics are still
scored). It contains 275,218 model calls in 39 frozen prediction files
(0.49 GiB), with zero error rows. The NIH scored set is 1,506 studies
(internal_test 1,054 + source_val 452); the 226 internal_train donor rows are
never read by the evaluation path. Round 2 adds 31,626 cells in two further
stages (second reasoning model + a marker probe), for 284,695 calls in the
41-stage coverage census. v9 adds a 32,184-call six-cell cross-modal panel
(3 local models x 1,788 images) and a 9,400-call relay arm; the delivered-cell
total is 326,830 and the known request total is 351,329 (Table 20 in the
manuscript). These are the numbers in `papers/main_v9/main.pdf` (the Chinese
mirror has not been regenerated for v9).

What is still not done: no human-validated Open-i labeller, no 22-cell
cross-modal dose-response (the six-cell probe is released), and no clinical
outcome. Those are stated as limitations, not simulated. See
`docs/42_academic_integrity_and_writing_standards.md`.

## 7. Hardware caveat

Everything was measured on a single RTX 4080 SUPER (32 GB) under WDDM. Batch-size
ceilings and throughputs in `docs/44_batch_sweep_matrix.md` are specific to that card,
and `docs/43_hardware_profiling_and_wddm_oversubscription.md` explains the GPU-memory
over-subscription behaviour under WDDM that produced them.
